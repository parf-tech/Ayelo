## P1 gains rapides

- [x] P1-1 « Gérer mon abonnement » : ligne toujours affichée dans Réglages, même si l'appel de statut échoue (ouvre alors la boutique de la plateforme) ; pour un Premium offert (`store: promotional`), message « Premium offert jusqu'au {date}. Rien à résilier. » au lieu d'une page de boutique vide ; même composant sur l'écran Premium. Libellé raccourci. Tests dans `settings.test.tsx` et `premium.test.tsx`.
- [x] P1-2 Suppression de compte : plus de déconnexion automatique ; écran de confirmation (suppression définitive dans N jours, comment annuler, abonnement à résilier avec accès à la gestion) puis bouton « Me déconnecter ». Le serveur révoque les sessions dès la demande : si une requête 401 déconnecte l'application avant, l'accueil réaffiche la confirmation (`deletionNotice`). Le formulaire mentionne l'abonnement avant la saisie du mot de passe. Libellé du bouton : « Supprimer mon compte ». Tests dans `settings.test.tsx` et `screens.test.tsx`.
  - Point d'attention : le backend n'implémente pas l'annulation par reconnexion (aucun code ne repasse un compte `deleting` à `active`) ; le texte renvoie donc au support pour annuler, il ne promet pas la reconnexion. À confirmer avec le backend.
- [~] P1-3 Consentements : liens « Lire les conditions d'utilisation » et « Lire la politique de confidentialité » sous les cases (page web ou repli). Test dans `screens.test.tsx`. Date de naissance AVANT les consentements : fait (voir P1-3 bis).
- [x] P1-3 bis Ordre d'inscription : date de naissance (S68, contrôle d'âge) puis consentements (S63) puis compte (S02). Changement contenu dans `signupMachine` : étape initiale `birthdate`, `AGE_PASSED` mène à `consents` (ou directement à `account` si les consentements sont déjà donnés), `CONSENTS_ACCEPTED` exige le jeton d'âge, `AGE_TOKEN_EXPIRED` ramène à S68 depuis S63 ou S02 en gardant les consentements, `AGE_REFUSED` possible depuis toute étape. Accueil et bascule connexion -> inscription ouvrent S68. Un mineur est donc refusé avant d'avoir lu ou accepté le traitement des données sensibles. Point d'attention : le jeton d'âge (10 minutes côté serveur) est maintenant émis avant la lecture des consentements ; s'il expire pendant la lecture, l'écran compte renvoie à S68 avec le message d'expiration (consentements conservés, une seule saisie de date à refaire). Tests : `__tests__/flow.test.ts` (machine et gardes réécrits), `__tests__/screens.test.tsx` (accueil, S68, S63, S02, jeton expiré).
- [x] P1-4 Signalement : motifs en cartes radio, bouton « Envoyer le signalement » désactivé tant qu'aucun motif n'est choisi (plus d'envoi au simple toucher) ; bouton « Signaler » sur l'écran de découverte et action d'accessibilité « Signaler » sur la carte (un toucher jusqu'à l'écran de signalement au lieu de trois).
